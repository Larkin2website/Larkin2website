Do not display an unconfirmed-registration notice or badge on the Training
Courses overview. This is a presentation-only change, not confirmation that
registration is open.

**Why:** The user asked to remove the unconfirmed-status notice from the selected
Training Courses section, without requesting changes to registration behavior.

**How to apply:** Keep the course visible through neutral presentation and retain
the underlying registration metadata and Apply-link safety checks.

Courses open for registration must appear first. First Credit Work Experience is
closed and belongs in the closed section, not a separate card above open courses.

**Why:** The user explicitly requested this ordering and placement.

**How to apply:** Group First Credit with the courses using its live registration
status rather than an independently positioned static card; recheck its status if
it changes in future.
