name: Role profile intake workflow
description: Owner-described role intake process and requirement to extend the existing portal.
---

People fill in the Role Profile template before staff input roles into the portal to be displayed. The owner wants to input the same information when creating a role and build on what currently exists.

**Why:** The user explicitly described this workflow and requested extending the current role-entry functionality.

**How to apply:** Treat template-based manual entry as the intended workflow. Extend existing role creation/editing rather than replacing it or assuming automatic document import is requested.

Role-specific technical questions are drafts for staff to use in their external application form, not permission to send them to a provider automatically. Recruitment planning remains internal; applicants receive only the role profile.

**Why:** The owner explicitly excluded changes to external application forms and application collection from the template-entry workflow.

**How to apply:** Do not infer an external form integration from saved technical questions. Any future provider automation requires a separate request.
