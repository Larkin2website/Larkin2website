---
name: Staff-facing production copy
description: Portal and CRM wording should not present the applications as testing workspaces.
---

Use neutral, production-facing wording on portal/CRM sign-in screens and
workspace labels. The user specifically wants phrases such as “development
access only”, “sign in for testing” and “restore verified staff sign-in” removed.

**Why:** The user is preparing the applications for production presentation.

**How to apply:** Use ordinary sign-in, workspace and help copy. Do not confuse
removing these labels with implementing secure authentication or certifying
production readiness. Preserve accurate operational errors and launch-blocker
documentation, and do not remove legitimate training/development programme names.
