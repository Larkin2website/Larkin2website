Update and polish the existing Larkin2 website, focusing on mobile responsiveness, menu navigation and the commitments section.

This is a refinement of the current website, not a redesign. Preserve the existing brand colours, fonts, wording and overall visual identity. Inspect the current implementation and reproduce the issues before making changes.

### 1. Correct mobile dimensions and alignment

Review the website section by section on mobile and fix proportions, spacing and alignment.

* Correct elements that extend beyond the screen or cause unintended horizontal scrolling.
* Resize headings, images, buttons and cards that feel oversized or cramped.
* Make side margins, internal padding and section spacing consistent.
* Fix awkward text wrapping, clipped content and excessive empty space.
* Remove restrictive fixed heights where they prevent content from fitting naturally.
* Preserve image proportions and ensure important subjects are not cropped incorrectly.
* Account for mobile browser bars when sizing full-screen sections.
* Keep buttons and interactive controls comfortably sized and spaced for touch.

Adapt column arrangements and content placement to smaller screens rather than simply shrinking the desktop layout. Preserve the desktop design while making these adjustments.

### 2. Fix menu behaviour and navigation alignment

Opening the menu and navigating to sections should feel precise and coordinated.

* Opening or closing the menu without selecting a link must preserve the underlying page’s scroll position.
* Ensure every menu link points to the correct page or section.
* When navigating within the same page, position the destination heading clearly below the fixed or sticky header.
* Calculate the scroll offset using the actual header height at the current breakpoint.
* Coordinate menu closing, background scroll unlocking and navigation so they do not cause competing movements, double jumps or incorrect landing positions.
* Fully close the menu after selecting a destination.
* Check whether existing smooth-scrolling or scroll-animation logic conflicts with anchor navigation. Resolve conflicts within the current implementation.
* Verify navigation remains accurate after images load, the viewport changes or the phone rotates.
* Apply the same alignment checks to buttons and other links that scroll to sections.

### 3. Replace the commitments layout with a carousel

Replace the overlapping commitments with a responsive horizontal carousel. This supersedes all earlier instructions for overlapping cards, scroll-based stacking or a vertical list.

#### Content and layout

* Display one complete commitment at a time.
* Each slide must contain its commitment number, title, supporting text and dedicated image.
* Preserve the existing wording and commitment order.
* Give every commitment its own unique, relevant image. Do not reuse one image across multiple commitments.
* On desktop, position the image and text side by side.
* On mobile, place the image above the text with comfortable spacing.
* Retain the original section background, brand colours and typography.
* Keep numbers, headings, images and controls clearly separated.

#### Navigation and transitions

* Add clearly visible previous and next arrow buttons.
* Include clickable pagination dots and a position indicator, such as “01 / 05”, calculated from the actual number of commitments.
* Support horizontal swipe gestures on mobile without interfering with normal vertical page scrolling.
* Use a smooth horizontal slide transition.
* Do not autoplay or advance slides through vertical scrolling.
* Disable the previous arrow on the first slide and the next arrow on the final slide.
* Keep arrows, pagination and the position indicator synchronised with the active slide.
* Navigating between slides must not unexpectedly move the page.

#### Responsiveness and accessibility

* Keep the carousel within the available screen width.
* Accommodate different text lengths without clipping content or causing abrupt section-height changes.
* Preserve image proportions and use appropriate cropping.
* Position navigation controls outside the text and image areas.
* Make buttons keyboard-accessible, with descriptive labels and visible focus states.
* Ensure inactive slides do not contain keyboard-focusable elements.
* Respect reduced-motion preferences by removing the sliding animation while preserving navigation.

Remove the previous sticky-card positioning, stacking animations and leftover scroll spacers. The commitments section must remain part of the normal page flow.

### 4. Verify the complete experience

Test representative widths of 360, 390, 430, 768, 1024 and 1440 pixels, plus mobile landscape.

Confirm that:

* There is no unintended horizontal scrolling, clipping or overlapping content.
* Every navigation destination lands at the correct position.
* Repeatedly opening, closing and using the menu causes no unexpected page jumps.
* Every commitment is fully readable and accessible.
* Carousel arrows, pagination, swipe gestures and keyboard controls work correctly.
* Vertical scrolling remains uninterrupted when interacting with the carousel.
* Reduced-motion preferences are respected.
* Mobile improvements do not introduce desktop layout problems.

Keep changes limited to these requirements. After implementation, summarise what changed, what was tested and any remaining limitations.
